What we check

Every check maps to one layer of agent readiness. A failure in any layer can silently kill a sale.

1. Can agents read it? JSON-LD structured data, price in HTML, llms.txt, robots.txt, sitemap, page load time, crawler access for GPTBot + ClaudeBot + PerplexityBot
2. Can agents extract correctly? Simulated AI shopper extracts price, availability, product name, return policy, shipping info. Run 10 times to measure accuracy and consistency.
3. Can agents act on it? Add-to-Cart semantics, variant selectors, guest checkout, cart API, checkout reachability, x402 wallet compatibility. Browser agent walks through the real flow.
4. Is it safe from manipulation? Hidden prompt injection scan: checks for invisible text in comments, hidden elements, and color tricks designed to hijack agent behavior.

FAQ

Yes. The free scan gives you your readiness score, headline findings, and per-check pass/fail verdicts. The paid report ($49) adds detailed evidence, sample AI agent responses, and copy-paste code fixes.

What stores do you support?

Currently optimized for Shopify stores. Most checks work on any e-commerce platform (WooCommerce, BigCommerce, custom). Shopify-specific checks (cart API, dynamic checkout) are clearly labeled.

Do you actually send AI agents to my page?

Yes. We run a real Claude-powered shopping agent against your page multiple times, asking it to extract price, availability, product name, and policies. We grade accuracy and consistency across runs.

Static checks: ~10 seconds. With AI extraction: ~30 seconds. Full scan with browser agent flows: 2-3 minutes. You watch results stream in live.
