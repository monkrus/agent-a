AI Extraction Testing

A real AI agent visited this page 10 times and tried to extract product details. Here's how it performed.

✗ RDY-006 Price extraction critical 7/10 correct

The AI agent extracted the price correctly 7 out of 10 times. In 3 visits, it returned $89.00 instead of $79.00 — likely reading a crossed-out "compare at" price from the HTML.

Ground truth: $79.00 (from JSON-LD)   Agent answers: $79.00, $79.00, $89.00, $79.00, $79.00, $79.00, $89.00, $79.00, $89.00, $79.00

Fix: The compare-at price ($89.00) is in a <span class="price--compare"> without clear semantic distinction. Wrap the selling price in <span itemprop="price"> and add aria-label="Selling price". Also ensure the JSON-LD offers.price matches the visible selling price exactly.
✓ RDY-007 Availability extraction high 10/10 correct

The AI agent correctly identified the product as "In Stock" across all 10 visits. JSON-LD availability URL matches visible page text.

? RDY-010 Shipping extraction medium 6/10 consistent

No shipping ground truth available on the page. The agent's answers were inconsistent: 4 visits returned "Free shipping over $75", 3 returned "Standard shipping $5.95", and 3 returned "Shipping calculated at checkout". The page has conflicting shipping messages in the footer vs. product section.

Fix: Consolidate shipping information into one visible location on the product page. Add a shippingDetails block to your JSON-LD Product. Remove the footer "Free over $75" text if the product page says "calculated at checkout" — agents read both and get confused.

Browser Purchase Flows

An AI agent opened a real browser and attempted 5 shopping journeys. Here's the step-by-step trace.

✗ RDY-017 Add to Cart critical Failed — 1/3 attempts

Agent trace (best attempt):

1 Navigate to product page — loaded successfully
2 Dismiss newsletter popup — clicked X button
3 Select variant "Queen / White" — clicked size dropdown, selected option
4 Click "Add to Cart" button — button not found. The ATC button is inside a Web Component shadow DOM that the agent cannot access.
Failure reason: The Add to Cart button is rendered inside a <custom-atc-button> shadow DOM element. AI agents using standard DOM queries cannot find or click it. The agent tried 3 alternative selectors and gave up after step 8.
Fix: Move the ATC button out of the shadow DOM, or add a standard <form action="/cart/add"> with a visible <button type="submit"> as a fallback. Also ensure the button has name="add" and aria-label="Add to cart".
✓ RDY-018 Search Discovery high Passed — 3/3 attempts
Agent navigated to homepage, found search bar, typed "silk pillowcase", found the target product in search results on all 3 attempts.
✗ RDY-019 Checkout Reachable critical Failed — blocked by ATC failure
Cannot reach checkout because add-to-cart fails (RDY-017). Fix ATC first, then this check will likely pass.
